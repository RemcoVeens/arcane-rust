# 🧙 Arcane Rust — The Terminal Grimoire

> *"Magic is just knowledge — the right incantations, the correct glyphs, and an understanding of the fundamental forces that govern the universe. Rust is no different."*

Welcome, aspiring **Rust Mage**. This is not a tutorial. This is a **quest**.

Every page in this book ends with a **Quest**: a small Rust crate in `exercises/` with a `TODO` and a set of tests — the **Gatekeepers**. The workshop runner, `wr`, checks your work and only opens the next door when the Gatekeepers are satisfied. No more guessing whether you did it right.

Every chapter ends with a **Project** that grows a real, playable terminal RPG: from a humble spellbook in Chapter 1 to a full concurrent battle saga in Chapter 8.

## 🗺️ The Road Ahead
