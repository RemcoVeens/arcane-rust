# 📜 Chapter 1 — The Call to Adventure

> *"Every Archmage was once an apprentice who could not light a candle. Today, you learn to speak."*

In this chapter you learn the basic grammar of Rust: variables, types, functions and control flow. Nothing here is hard — but Rust has opinions (immutability by default, no implicit conversions, everything is an expression), and these quests make sure you feel them in your fingers.
